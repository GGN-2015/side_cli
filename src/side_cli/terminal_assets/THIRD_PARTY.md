# Embedded terminal assets

- `xterm.js` and `xterm.css`: `@xterm/xterm` 6.0.0, `lib/xterm.js` and
  `css/xterm.css` from the npm release; license in `LICENSE-xterm.txt`.
- `addon-fit.js`: `@xterm/addon-fit` 0.11.0, `lib/addon-fit.js` from the npm
  release; license in `LICENSE-addon-fit.txt`.

These assets are bundled so the desktop terminal runs without a CDN.
